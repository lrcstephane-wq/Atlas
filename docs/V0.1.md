# Périmètre fonctionnel V0.1

## Forge

### Composants

- choix d’une racine de bibliothèque ;
- parcours récursif sécurisé des fichiers `.TOP` ;
- aucune tentative de lecture du contenu TopSolid ;
- récupération du chemin relatif, de la bibliothèque, de la famille, du nom et de l’éventuelle image `.top.png` ;
- lecture des marqueurs `#V=`, `#I=`, `#R=` et `#C=` présents dans le nom ;
- fiche brouillon même si le nom est non conforme ;
- métadonnées métier destinées à être reprises par les meubles ;
- validation finale réservée à un utilisateur autorisé.

### Meubles

- fiche meuble indépendante ;
- composition déclarée en choisissant les fiches composants ;
- agrégation lisible des capacités et compatibilités ;
- `principe_construction` et correspondance `Sens_Montage` ;
- publication dans l’aperçu client ;
- forçage possible, mais obligatoirement justifié et tracé.

## Catalogue Atlas

- recherche des meubles publiés ;
- liste virtualisée ;
- aperçu de la fiche client ;
- emplacement prévu pour le glisser-déposer vers TopSolid ;
- distribution et authentification client volontairement non figées dans cette version.

## Collaboration

- catalogue partagé sur le réseau ;
- révision optimiste pour détecter une modification faite par un autre poste ;
- verrou court pendant l’écriture ;
- sauvegardes tournantes ;
- journaux mensuels ;
- comptes administrateur, éditeur, validateur et lecture seule.

## Limites volontaires

- pas de lecture interne des `.TOP` ;
- pas encore de synchronisation hors réseau ;
- pas encore de base de données serveur ;
- pas encore de comptes clients ;
- pas encore de glisser-déposer d’un meuble non relié à son fichier `.TOP`.
